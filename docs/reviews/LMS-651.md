## Findings

1. **[BLOCKER] Slow present-path work repeats a running processed count.**

   The rate limiter at [internal/daemon/converge.go:117](../../internal/daemon/converge.go#L117) emits after one second even when `pathsSinceReport` is zero. It suppresses equal counts only for final callbacks. Every callback then writes detached job state at [internal/daemon/background_sync.go:548](../../internal/daemon/background_sync.go#L548).

   A deterministic 256-path probe captured `256 of 256` before the first semantic write. After the first write took 1.1 seconds, the next running job version still reported `256 of 256`. Its `UpdatedAt` value advanced from `08:03:18.561026 UTC` to `08:03:19.663421 UTC`.

   The helper test at [test/live/missing_watcher_path_live_test.go:73](../../test/live/missing_watcher_path_live_test.go#L73) only proves that the polling helper recognizes two constructed equal values. It stays green while production repeats the count. The requested duplicate-progress red-green proof therefore has no green head.

   Minimal fix: suppress every callback after a report when `pathsSinceReport == 0`. Add a deterministic production-path test that fails on this head and passes after the fix.

2. **[SHOULD-FIX] Watcher comments still promise deletion.**

   [internal/daemon/eventqueue.go:12](../../internal/daemon/eventqueue.go#L12) says an absent path is deleted and that delete supersedes reindex. [internal/daemon/watcher_test.go:206](../../internal/daemon/watcher_test.go#L206) says a deleted source enqueues for removal. LMS-651 now retains that path until full sync.

   Minimal fix: update both claims and the related failure text to describe classification and retention.
