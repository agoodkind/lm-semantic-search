# Tool call indexing design

This conversation RPC and row replacement design is superseded. The [cross repository coordination plan](https://github.com/agoodkind/clyde/blob/docs/embedded-conversation-search/docs/superpowers/plans/2026-09-27-shared-search-coordination.md) controls execution. Clyde C1 retains the display and language fields, raw input fallback rules, UTF-8 validation, token deduplication, and tool-name prefix for each prepared part. The [shared library design](2026-09-27-shared-search-library-design.md) defines source occurrence storage. Existing rows remain available until a deliberate migration or retirement.
