# Generic collection search plan

This fixed depth RPC search plan is superseded. The [cross repository coordination plan](https://github.com/agoodkind/clyde/blob/docs/embedded-conversation-search/docs/superpowers/plans/2026-09-27-shared-search-coordination.md) controls execution. The [library design](../specs/2026-09-27-shared-search-library-design.md) defines complete filtered search; [L2 lexical ranking](2026-09-27-shared-search-l2-lexical.md) and [L3 query execution](2026-09-27-shared-search-l3-query.md) define LMS implementation. Existing collections remain intact until deliberate migration or retirement.
